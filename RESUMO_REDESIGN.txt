📊 ESTRUTURA DE DADOS:
───────────────────────────────────────────────────────────────────────────────

Event Object:
{
  id: string,
  title: string,           // Nome do evento
  date: "YYYY-MM-DD",     // Data
  times: ["HH:MM"],       // Array de horários
  venue: string,          // Nome do local
  venue_addr: string,     // Endereço
  ticketLink: string,     // URL de ingressos
  desc: string,           // Descrição
  price: string,          // Preço
  platform: string        // Plataforma de origem
}

Venue Object:
{
  name: string,           // Nome do local
  addr: string            // Endereço completo
}

Artist Object:
{
  [name]: number          // { "Banda X": 3, "Artista Y": 1 }
}

🎬 COMO USAR:
───────────────────────────────────────────────────────────────────────────────

1. Abrir Aplicação
   - Abra index.html no navegador
   - Dashboard carrega automaticamente

2. Visualizar Home
   - Veja stats (Eventos, Locais, Artistas, Próximo)
   - Explore eventos em cards responsivos
   - Use botões de editar/deletar

3. Explorar Locais
   - Clique em "Locais" no topbar
   - Veja grid com 24 venues
   - Cada card mostra nome e endereço

4. Ver Artistas
   - Clique em "Artistas" no topbar
   - Grid com artistas únicos
   - Contagem automática de eventos

5. Usar Chatbot
   - Clique no widget no canto direito
   - Escreva uma mensagem
   - Pressione Enter ou clique ➤
   - Interaja normalmente

6. Mudar Tema
   - Clique em ☀️ ou 🌙 no topbar
   - Interface alterna entre claro/escuro
