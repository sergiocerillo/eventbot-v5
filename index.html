Configurações

  1. Google Cloud Console → APIs → Credenciais → seu OAuth Client ID → Origens JavaScript autorizadas → adicionar ambas:
    http://localhost:8080 e http://127.0.0.1:8080
  2. openrouter.ai/keys → Create Key (gratis)
  3. Google Calendar → Configuracoes → Integrar agenda → copiar Calendar ID
Login permanente — sem popup

  2. Nome qualquer (ex: eventbot) → Create → Done
  3. Clique na conta → aba Keys → Add Key → JSON → baixe
  4. Google Calendar: compartilhe com o email [email protected] → permissao Fazer alteracoes nos eventos
